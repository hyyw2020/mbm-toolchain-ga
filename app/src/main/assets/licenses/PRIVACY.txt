Mixed Bug Method（MBM）隐私政策
================================
版本：v1.0.72 ｜ 生效日期：2026-11-06 ｜ 适用版本：v1.0.72 及之后版本
（历史版本请查阅随版本分发的 NOTICE 与仓库提交记录）

本版相对 v1.0.39 的主要修订：纠正「屏幕记忆为独立可选 APK」等与代码
不符的描述；补全实际申请的权限清单；披露 v1.0.40~72 新增的学习状态与
上下文预测数据；修正备份排除、离线许可查看等措辞。

一、总则与权限
--------------------------------
Mixed Bug Method（以下简称「本产品」）是基于开源项目 fcitx5-android
开发的离线输入法。设计目标是「功能全在本机完成」：主输入法未申请
INTERNET 与 ACCESS_NETWORK_STATE 权限（已对最终签名 APK 实测确认），
从系统层面不具备联网能力；产品内不含任何统计、广告或远程崩溃上报组件。

为便于您核对，本产品最终 APK 实际申请的系统权限与高敏感能力如下：

  - 振动（VIBRATE）：按键反馈。
  - 通知（POST_NOTIFICATIONS）：前台服务常驻提示。
  - 前台服务（FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC）：
    屏幕记忆无障碍服务保活，仅在您开启该服务后使用。
  - 查询全部应用（QUERY_ALL_PACKAGES）：用于「应用名即时候选」功能，
    枚举本机有启动器图标的应用名称并写入本机词库；不上传应用列表。
    该功能失效时仅影响候选，不影响输入。
  - 生物识别（USE_BIOMETRIC / USE_FINGERPRINT）：由 androidx.biometric
    依赖声明；v1.0.39 起查看已捕获内容不再要求设备凭证，当前版本不
    以生物识别作为数据访问门。
  - 无障碍服务（BIND_ACCESSIBILITY_SERVICE）：屏幕记忆能力，默认关闭，
    仅当您在本系统「无障碍」设置中显式开启后由系统拉起；可读取窗口
    可见文字并使用系统截图能力做本机 OCR。详见第二节第 4 项。
  - 文档提供者（DocumentsProvider，exported）：由 signature 级
    MANAGE_DOCUMENTS 权限保护，供系统文件选择器导入/导出本机文件，
    普通第三方应用无法访问。

二、我们处理的数据及用途
--------------------------------
1. 输入内容（主输入法）
   - 您通过键盘输入的字符仅用于生成本次输入的候选结果，处理全程在
     本机内存中完成，不作留存，不写入日志。
   - 经您启用的本地学习功能会在本机应用私有目录保存以下数据，
     用于改进候选排序与预判；各项均可在设置中随时清空：
       · 用户词库、自定义词组、智能词库：本机词频、上屏时间、
         二元/三元词共现计数、高频固定短语。
       · 用户选择优先级状态（mbm_choice_boost）：您主动从候选栏
         选中的词、对应的拼音键、选择次数、最近选择时间、连续选择
         次数、上一条上屏词，以及用于排序的软层评分数据。
       · 上下文预测状态（mbm_context_pred，v1.0.72 新增）：由上述
         本地共现统计推导、当前生效的「下一词」预测候选列表。
         它是「最近一次上屏的下一步」快照，每次上屏都会全量替换，
         不会长期累积。
     v1.0.72 起，学习到的词条会同时按「拼音首字母键」与「全拼键」
     写入本机词组表，以便不同拼音输入习惯都能获得一致的排序。
     所有键与词条均在本机生成，不含任何预置训练语料。
   - 当系统或应用声明当前输入框为密码类（密码型 inputType、imeOptions
     声明「不建议个性化学习」、Autofill 密码提示等）时，本产品自动
     进入隐私模式：不学习、不记忆、不索引、不记录剪贴板历史、不产生
     上下文预测，键盘界面同步显示隐私状态提示。该过滤在输入服务入口
     与学习模块内各有一次校验。
   - 「应用名即时候选」会读取本机已安装应用的名称（见第一节
     QUERY_ALL_PACKAGES），仅在本机生成候选，不上传。

2. 剪贴板历史（主输入法）
   - 您选择保留的剪贴板内容仅保存于本机应用私有目录的数据库中，
     用于剪贴板面板的历史回溯与快速上屏；不上传、不与任何第三方
     同步。隐私模式下不记录剪贴板历史。
   - 数据库为 SQLCipher 加密；超过内联阈值的大文本以外置文件
     存储（filesDir/clipblobs/），文件经 AES-256-GCM 分块静态加密，
     密钥由 Android Keystore（StrongBox 优先）中的 AES-256-GCM 密钥
     信封加密保护，文件被整体提取也无法解密。

3. 手写输入（主输入法）
   - 手写笔画在本机内存中由随应用分发的离线模型（ncnn / MobileNetV2
     INT8 量化模型与字表）识别，笔画数据与识别结果不留存、不上传。
     该模型为通用离线模型，不含您的任何输入数据。

4. 屏幕文字捕获（「屏幕记忆 Recall」）
   - v1.0.36 起该能力**内嵌于主输入法 APK**、与输入法同进程运行，
     不再是独立安装的可选插件 APK。它在系统「无障碍」设置中默认
     关闭，仅当您显式开启后由系统拉起；关闭时不占用后台资源。
   - 开启后，服务读取当前屏幕上的可见文字，保存于本机 SQLCipher
     加密数据库（数据库口令由 Android Keystore 中 StrongBox 优先的
     AES-256-GCM 密钥信封加密，密钥材料不可导出），大文本外置文件
     （filesDir/recall_blobs/）另有 AES-256-GCM 分块静态加密，仅供
     您事后检索。
   - v1.0.39 起：采集火力全开，应用内不再设置任何窗口级封锁
     （密码框、系统敏感窗口、金融类应用均照常捕获）。系统「高级保护
     模式」不再停用本服务。卡号 / 身份证 / 验证码等敏感词条仅打标
     降权（照常收录，仅不占候选首位），不丢弃、不屏蔽。唯一例外：
     FLAG_SECURE 安全窗口的系统截图由 Android 返回黑帧，属 OS 层
     行为；无障碍服务配置保留 accessibilityDataSensitive="auto"，
     由系统自行决定是否规避被标记为敏感数据的窗口，本应用不绕过。
   - OCR 兜底路径使用无障碍服务自带的截图能力在本机识别图片化
     内容（离线 PP-OCRv6 模型），截图在处理完毕后立即回收，不落盘、
     不上传。
   - v1.0.39 起：查看已捕获内容不再要求设备凭证验证；静态安全由
     SQLCipher 加密数据库与 Keystore 信封加密密钥承担。
   - 每次导入、导出、删除、清理都会写入本机审计日志
     （filesDir/recall_audit.log），供您自查数据去向。

5. 全局计算器候选（v1.0.39 起）
   - 任意输入框中，光标前文本以合法算式结尾（如 123+456）时候选栏给出
     【579】与【123+456=579】，点选即原子地替换为所选内容；与当前所用
     键盘布局无关。求值由纯 Kotlin 标准库在本机内存中完成，无任何网络
     请求、不上传、不落盘；该功能全局默认开启，不设开关，也不采集任何
     数据。密码类字段与拼音组合过程中不启用该功能。

6. 密码生成器（主输入法）
   - 密码在本机随机生成并直接填入当前输入框，不记录、不上传。

三、数据存储与安全
--------------------------------
- 所有数据仅保存于本机（应用私有目录及应用专属外部目录），不会
  离开您的设备。
- 本产品设置 android:allowBackup="false"，并在 Android 12+ 数据提取
  规则与旧版备份规则中对 sharedpref / database / file / external
  四个域**整域显式排除**云备份与换机迁移（v1.0.72 起由「排除若干
  具体路径」改为整域排除，覆盖 recall_blobs / clipblobs / 审计日志 /
  学习状态等全部目录），备份与迁移工具不会获取上述数据。
- 「屏幕记忆」数据库采用 SQLCipher 透明加密；剪贴板与「屏幕记忆」
  的大文本外置文件采用 AES-256-GCM 分块静态加密（单块 256KB，块序号
  进认证数据，篡改/重排即校验失败）；密钥材料在 Keystore 中不可导出。
  升级时历史明文文件自动识别、照常可读，并在下次写入同内容时就地
  转为密文。
- 本产品发布 APK 使用开发者自签名证书签名（未加固、未混淆），
  覆盖安装不清除上述本机数据。

四、数据共享与出境
--------------------------------
本产品不与任何第三方共享您的数据，不进行任何形式的网络传输，
不存在数据出境。应用内「关于 → 开源许可」全部离线渲染：AGPL-3.0
全文、NOTICE 与上游组件清单随 APK 置于 assets/licenses/，第三方库
条目在应用内弹窗展示许可名称与 SPDX 标识，不跳转浏览器、不联网
（v1.0.72 起）。

五、第三方组件
--------------------------------
本产品集成的第三方库均仅用于本机计算与本地存储，主要包括：
  - fcitx5 / libime / fcitx5-lua / fcitx5-chinese-addons 及各上游
    输入法引擎（拼音、手写、OpenCC 转换等）；
  - ONNX Runtime Android + PP-OCRv6 离线模型（本机 OCR）；
  - ncnn + Ismantic/Handwritten 离线手写模型（本机手写）；
  - SQLCipher Android（本地加密数据库）、AndroidX Room / DataStore /
    Biometric / Security Crypto（本地存储与偏好）；
  - Timber（仅输出本机日志，崩溃栈经脱敏）、AboutLibraries 及
    AndroidX / Material / Splitties / Arrow 等界面与工具库。
各组件许可标识可在应用内「关于 → 开源许可」离线查看，完整清单与
条款见随 APK 分发的 NOTICE.txt / UPSTREAM.txt 与仓库根目录 LICENSE。

六、您的权利
--------------------------------
- 删除：「屏幕记忆」时间线支持单条、批量与全部删除；剪贴板历史、
  用户词库、智能词库、自定义词组、用户选择优先级状态与上下文预测
  状态均可在设置中清空或关闭学习开关（关闭时自动撤回已注入的预测
  候选）；卸载应用即删除其全部数据。
- 退出：关闭对应开关即可停用各项本地学习与捕获功能；在系统
  「无障碍」设置中关闭屏幕记忆服务即彻底停止捕获。
- 查询：应用内「数据去向」审计日志记录每一次导出与清理操作。

七、未成年人保护
--------------------------------
本产品不面向未成年人定向采集任何数据。

八、政策更新
--------------------------------
本政策随产品版本更新。涉及数据处理方式重大变更的，将在新版本中
以显著方式提示。
