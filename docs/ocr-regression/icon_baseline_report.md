## 3. 关键结论：图标 score vs 真字 score 是否可分

- 图标被误识框 score ∈ [0.1860, 0.7335]（n=9）
- 真实文字框 score ∈ [0.8761, 1.0000]（n=36）
- 区间重叠宽度 = **0.0000**

**判定：完全可分 → A（置信阈值）在本套件可作主判据。**

> ⚠️ 以上是**合成图**结论。真机 Material 矢量图标更精细，rec 可能给出更高
> 置信度，间隙可能收窄甚至消失。**阈值必须在真机截图上重新标定。**
